# Live Sports Scores 1.3

API-Football v3 with league filtering derived from the selected bot-topic
audience. Premier League maps to API-Football league `39`; Spanish League and
La Liga map to league `140`. Global and follower installations retain the
provider's `live=all` behavior.

The API key is supplied through Weynear's credential manager. The installer
cannot override the reviewed audience-to-provider mapping.
